# Q-Guard — Quantum Fraud Detection System

**Winner — OLG Sponsor Track, University Hackathon**

Q-Guard is a fraud detection platform designed to identify suspicious financial and gaming activity using machine learning. It combines a web interface with an API-driven detection system and explores quantum-hybrid approaches to fraud detection.

## Highlights
- Machine-learning-based detection of potentially fraudulent activity
- API and web interface for interacting with the system
- Experimental quantum-hybrid fraud detection models

**Tech stack:** Python, LightGBM, FastAPI, React
